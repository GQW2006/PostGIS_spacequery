# 一、设计目标与原则

## 1.1 这个系统给谁用

| 用户 | 真实使用场景 | 设计含义 |
| --- | --- | --- |
| 规划/研究人员 | 坐下来分析半小时以上，要看统计、要导出 | 信息密度可以高，要有表格和图例 |
| 公众查询 | 手机或电脑上查"我家附近有没有小学"，30 秒内要答案 | 主流程必须极短，不能藏功能 |
| 汇报演示 | 投影到大屏，边走边讲 | 要有"一键回到全图"、字号不能太小 |

## 1.2 四条设计原则

1. **地图是主角，面板是配角。** 面板总宽度不超过屏幕 30%，可随时收起。
2. **一眼看懂，再看细节。** 先给颜色和数量，点击后才给属性明细。
3. **所有视觉编码都可解释。** 每个颜色、每个符号都必须能在图例里找到。
4. **不做花哨动效。** 只在"地图飞向某处"和"面板展开"两处用动画，其余即时响应。

# 二、信息架构

```
系统
├── 首页（地图工作台）
│   ├── 顶栏
│   │   ├── 系统名 / Logo
│   │   ├── 全局搜索框
│   │   ├── 底图切换
│   │   └── 用户入口（登录/头像）
│   ├── 左侧面板（可收起）
│   │   ├── Tab 1：图层
│   │   │   ├── 基础底图
│   │   │   ├── 行政区（市界 / 区县）
│   │   │   ├── 设施点位（小学 / 中学 / 菜市场）
│   │   │   ├── 人口（栅格热力）
│   │   │   └── 分析结果（服务区 / 分级面）
│   │   └── Tab 2：分析
│   │       ├── 最近设施查询
│   │       ├── 服务区覆盖
│   │       └── 区县统计
│   ├── 地图区
│   │   ├── 图层渲染
│   │   ├── 控件（缩放 / 比例尺 / 复位）
│   │   └── 弹窗 / 气泡
│   ├── 右侧抽屉（点击要素后出现）
│   │   ├── 要素详情
│   │   └── 所属行政区
│   └── 底部状态栏
│       ├── 光标经纬度
│       ├── 当前缩放级别
│       └── 当前视口要素数
└── 登录页（独立页面）
```

> **为什么只有两个 Tab**：图层和分析是两类心智模型（"我要看什么" vs "我要算什么"），
> 混在一起会让人找不到。多于两个 Tab 又会增加认知负担。

# 四、视觉规范

## 4.1 色板

**界面色**

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色 | `#1668DC` | 按钮、选中态、链接 |
| 主色悬停 | `#0E5AC4` | |
| 成功 | `#00B42A` | |
| 警告 | `#FF7D00` | 数据缺失提示 |
| 错误 | `#F53F3F` | |
| 页面背景 | `#F0F2F5` | |
| 面板背景 | `#FFFFFF` | |
| 分割线 | `#E5E6EB` | |
| 文字主 | `#1F2329` | 标题、正文 |
| 文字次 | `#646A73` | 辅助说明 |
| 文字禁用 | `#C9CDD4` | |

**设施符号色**（三类必须一眼可分）

| 设施 | 色值 | 形状 | 直径 |
| --- | --- | --- | --- |
| 小学 | `#1668DC` 蓝 | 实心圆 | 8px |
| 中学 | `#722ED1` 紫 | 实心方块（旋转 45°） | 8px |
| 菜市场 | `#00B42A` 绿 | 实心圆 | 7px |

> 形状 + 颜色双重编码，色弱用户也能分辨。

**人口栅格色带**（顺序色带，白→蓝→黄→红）

```
0 人 ──── #FFFFFF
低密度 ── #D6E4F0
中密度 ── #7BA7D9
较高 ──── #F5D76E
高密度 ── #E8743B
极高 ──── #9C1650
```

**可达性分级色带**（发散色带，好→差）

| 等级 | 阈值（示例） | 色值 |
| --- | --- | --- |
| 优 | < 500 m | `#0050B3` |
| 良 | 500–1000 m | `#4E9BE8` |
| 一般 | 1000–1500 m | `#FAAD14` |
| 差 | > 1500 m | `#F5222D` |

> 分级色带**必须配图例**，且阈值要在界面上可见（不能藏在后台配置里）。

## 4.2 字体与字号

```css
font-family: -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 层级 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| H1 | 20px | 600 | 页面标题 |
| H2 | 16px | 600 | 面板标题 |
| Body | 14px | 400 | 正文、列表 |
| Caption | 12px | 400 | 辅助信息、图例、状态栏 |
| Number | 24px | 600 | 统计大数字（如"68.4%"） |

> 数字统一用等宽字体（`font-variant-numeric: tabular-nums`），
> 否则统计表里的数字会跳来跳去。

## 4.3 间距与圆角

- 基础栅格 **8px**：所有间距取 8 的倍数（8 / 16 / 24 / 32）
- 圆角：按钮 6px，面板 8px，弹窗 8px
- 阴影：`0 2px 8px rgba(0,0,0,.08)`，只在浮层使用，面板用边框不用阴影

# 五、地图符号与标注

| 要素 | 样式 |
| --- | --- |
| 市界 | 线宽 2px，色 `#1F2329` |
| 区县界 | 线宽 1px，色 `#8A8F99`，虚线 |
| 区县填充（分级图） | 无描边，按分级色填充，透明度 85% |
| 设施点 | 见 4.1，白色描边 1.5px |
| 服务区（缓冲区） | 填充 `#1668DC` 透明度 15%，描边 `#1668DC` 1.5px |
| 高亮要素 | 外发光 2px `#FAAD14` |

**缩放级别策略**

| 缩放 | 显示策略 |
| --- | --- |
| Z < 9（全域） | 只显示区县面 + 聚合气泡 |
| Z 9–12 | 聚合气泡 + 区县名 |
| Z ≥ 12 | 原始点位 + 设施名标注 |
| Z ≥ 15 | 增加道路名称 |

> 聚合气泡显示数量，点击后展开。这是防止全域几万个点卡死的关键。

# 六、关键交互流程

## 6.1 查"我家附近有什么"

```
用户在地图点击某位置
   → 地图打一个临时标记
   → 右侧抽屉打开，显示该点所属行政区
   → 抽屉内列出：500m 内 2 所小学 / 1 所中学 / 3 个菜市场
   → 点击任一条目，地图飞向该设施并高亮
```

**要点**：一次点击给出"归属 + 周边"两个信息，不要让用户点两次。

## 6.2 看某区县的设施水平

```
用户点击某个区县面
   → 区县高亮
   → 右侧抽屉显示：设施数量 / 每万人设施数 / 平均最近距离
   → 抽屉底部"只看这个区"按钮
   → 点击后其他区县变灰，设施点只留本区
```

## 6.3 做一次服务区覆盖分析

```
切到"分析" Tab
   → 选设施类型（默认小学）
   → 拖半径滑块（默认 1000m）
   → 地图实时渲染缓冲区（松手后 500ms 计算，避免每帧请求）
   → 面板显示覆盖人口 / 覆盖率
   → 点"导出"→ 下载 GeoJSON
```

**要点**：滑块拖动时**不请求**，松手（`change` 而非 `input`）后才算。

## 6.4 搜索并定位

```
顶栏输入关键词
   → 下拉显示前 10 条结果（名称 + 区县）
   → 回车或点击 → 地图 flyTo，缩放至 Z15
   → 打开右侧抽屉显示详情
```

# 七、状态设计

任何异步操作都必须有这三种状态，不能只做"成功"那条路。

| 状态 | 表现 |
| --- | --- |
| **加载中** | 面板内骨架屏（不用整页转圈）；地图区不遮挡 |
| **空数据** | 插图 + 一句话说明 + 建议操作（"当前视口内没有设施，试试缩小地图"） |
| **错误** | 明确原因 + 重试按钮（"统计服务响应超时，请重试"），不要只显示"出错了" |

**空闲态**（首次进入）：左侧默认展开"图层"，地图默认定位到成都市域全图，
右侧抽屉关闭，状态栏显示数据更新时间。

# 八、响应式

| 断点 | 布局调整 |
| --- | --- |
| ≥ 1366px | 完整三栏 |
| 1024–1365px | 左侧面板收窄至 280px |
| 768–1023px | 左侧面板默认收起，改为抽屉式 |
| < 768px | 单栏：地图全屏 + 底部抽屉（上滑展开），分析面板改为全屏浮层 |

> 移动端不是主战场，但"公众查询"这个角色会在手机上用，
> 至少要保证"点地图看附近设施"这条路能走通。

# 九、可访问性

- 所有颜色信息都有**形状 / 文字**作为第二编码（色弱可用）
- 文字与背景对比度 ≥ 4.5:1
- 所有按钮有 `title` 或 `aria-label`
- 键盘可完成：搜索、切换图层、关闭抽屉（`Esc`）
- 地图区提供"文字版结果"（右侧抽屉本身就是文字版）
