# 3. 变更清单

## P0-1　窄屏顶栏溢出

**文件**：`src/components/TopBar.vue`

**现状**（实测 390px 视口）：标题 `white-space: nowrap`（:128）固定 252px，`.search-wrap` 为 `flex:1; max-width:420px`（:140-144），导致搜索框被裁切、底图与登录按钮被挤出视口。

**改法**

1. `.title`（:124-129）追加：
   ```css
   min-width: 0;
   overflow: hidden;
   text-overflow: ellipsis;
   ```
2. `.search-wrap`（:140）追加 `min-width: 0;`（否则 flex 子项不会收缩）
3. 新增断点，置于样式块末尾：
   ```css
   @media (max-width: 767px) {
     .title { max-width: 40vw; }
     .search-wrap { display: none; }   /* 搜索收进图标入口，见下 */
   }
   ```
4. 搜索的窄屏入口：在 `.title` 右侧放一个 32×32 图标按钮（复用现有 `.icon-btn` 样式），点击后把搜索框以 `position:absolute; left:16px; right:16px; top:56px` 展开在顶栏下方一层。**这是唯一的交互新增**，其余保持原样。

**验收**：390px 下三个控件（标题、底图、登录）都在视口内；无横向溢出（`document.documentElement.scrollWidth <= 390`）。

## P0-2　状态栏信息重叠

**文件**：`src/components/StatusBar.vue`

**现状**：`.coord { min-width: 168px }`（:35-37）不收缩；`.status` 为 `display:flex; gap:16px`（:23-34），390px 下四项互相压字。

**改法**

1. `.coord`（:35）改为：
   ```css
   .coord { white-space: nowrap; }
   ```
   删掉 `min-width: 168px`——它本意是防抖动，但设了固定最小宽反而挤爆窄屏。
2. `.status` 追加 `overflow: hidden;`，并给非关键项加 `flex: 0 0 auto`。
3. 新增断点：
   ```css
   @media (max-width: 767px) {
     .status { gap: 8px; }
     .source, .truncated { display: none; }  /* 元信息与截断提示在窄屏让位 */
   }
   ```
   `.source` 与 `.truncated` 是次要信息，窄屏隐藏不损失任务完成能力。

**验收**：390px 下坐标、缩放级、设施数三项不重叠；1440px 下四项仍齐全。

## P1-1　空态呈现

**文件**：`src/components/AnalysisPanel.vue`

**现状**：未计算时，统计位渲染 `— 人` / `— %`，实测 `24px / 600 / #1F2329`——一个大号满墨粗体破折号，读起来像渲染错误而不是「暂无数据」。

**改法**

1. 模板中统计数值所在元素（含 `— 人`、`— %` 的位置）改为条件渲染：
   ```html
   <span v-if="hasValue" class="num">{{ value }}</span>
   <span v-else class="num-empty">尚未计算</span>
   ```
2. 新增样式：
   ```css
   .num-empty {
     font-size: var(--fs-body);
     font-weight: 400;
     color: var(--c-text-2);
   }
   ```
3. 单位与数字之间加 4px（见 P3-2），空态下单位一并隐藏。

**验收**：未计算时显示「尚未计算」四字，14px 常规字重次要色；计算后恢复 24px 数字。

## P2-1　行政区颜色回归设计系统（最高杠杆）

**文件**：`src/components/MapView.vue`（:113-122）、`src/stores/layer.js`（:52、:55）

**现状**：区县界 / 市界由 GeoServer WMS 栅格提供（`layer.js:52,55`，`geoserver.js` 拼 tile URL），颜色由 GeoServer 默认 SLD 决定——**默认为灰色实填充**，压住整块底图，且这个灰不在 `tokens.css` 里。前端改样式对它无效。

**改法**

1. `layer.js:52,55`：把 `wms-districts` 与 `wms-boundary` 的默认 `visible` 改为 `false`（图层项保留，用户仍可手动打开）。
2. `MapView.vue:113-122` 已有 `district-mask`（`fill-opacity: 0`），**保留不动**；在其后新增边界线图层：
   ```js
   m.addLayer({
     id: 'district-line',
     type: 'line',
     source: 'districts',
     paint: {
       'line-color': '#8a8f99',
       'line-width': 0.8,
       'line-opacity': 0.55,
     },
   })
   ```
3. 市界同样用 `chengdu_boundary` 数据加一层 line：`line-color: '#1f2329'`、`line-width: 1.6`。

**说明**：这一步把「面积最大的颜色」从外部服务手里收回 `tokens`/组件，后续任何配色调整才有意义。**不要**去改 GeoServer 的 SLD——那会让前端样式再次失去控制权。

**验收**：1440px 首屏不再出现灰板；行政区只剩描边；`tokens.css` 里能查到用到的每个颜色。

## P2-2　蓝色语义拆分

**文件**：`src/styles/tokens.css`（:5、:19）、`src/components/MapView.vue`（:133-145）

**现状**：`--c-school: #1668dc`（:19）与 `--c-primary: #1668dc`（:5）同值。同一个蓝同时是：tab 选中、主按钮、聚合点、小学点位、服务区填充/描边、图例圆点——强调色失去信号作用。

**改法**

1. tokens 新增（**保留原值不改**，只补语义）：
   ```css
   --c-action: #1668dc;   /* 可点击动作：按钮、选中态 */
   --c-cluster: #0e5ac4;  /* 聚合点：比单点深一档 */
   ```
2. 把所有**按钮 / tab 选中**引用从 `--c-primary` 换成 `--c-action`（值相同，无视觉变化，但语义可独立演进）。
3. `MapView.vue:133-145` 聚合点改为**空心环**，与单点用形状区分，不只靠颜色：
   ```js
   paint: {
     'circle-color': 'rgba(14,90,196,0.10)',
     'circle-radius': ['step', ['get','point_count'], 14, 50, 18, 200, 24],
     'circle-stroke-width': 2,
     'circle-stroke-color': '#0e5ac4',
   }
   ```
   数字文字（`poi-cluster-count`，#146-156）颜色从 `#ffffff` 改为 `#0e5ac4`（空心背景下白字不可读）。

**验收**：缩放时能一眼分辨「单点 / 聚合」；主按钮与设施点不再共享同一令牌。

## P2-3　字号与控件高度归一

**文件**：`src/styles/tokens.css`（:38-43）、`src/components/SidePanel.vue`

**现状**：实测存在五个字号 `18 / 14 / 13.3333 / 12 / 24`，其中 **13.3333px** 出现在按钮和分组标题（从 em 继承的非设计值），与 14px 仅差 0.67px——既无法察觉又不构成层级。控件高度并存 39（tab）/ 40（行）/ 36（按钮）三档。

**改法**

1. tokens 新增：
   ```css
   --fs-ui: 13px;   /* 紧凑 UI 文字：按钮、分组标题 */
   ```
2. 列出所有 `font-size: 13.3333px`（或等价的 em/rem 表达式）替换为 `var(--fs-ui)`。
3. `SidePanel.vue` 中 tab 高度 39 → **40px**，与行高统一。最终只允许两档控件高度：**36（按钮）/ 40（行与 tab）**。

**验收**：`grep` 不到 13.3333；渲染后字号集合为 `{12, 13, 14, 18, 24}`；控件高度集合为 `{36, 40}`。

## P2-4　状态栏元信息配色

**文件**：`src/components/StatusBar.vue`（:44-46）

**现状**：`.source { color: var(--c-text-disabled) }` —— `#c9cdd4` 在白底上对比度约 **1.6:1**，远低于 AA 要求的 4.5:1。信息被当成「禁用态」渲染。

**改法**：`.source { color: var(--c-text-2); }`（`#646a73`，约 5.4:1）。

**注意**：`--c-text-disabled` 保留原值，它是对的——错的是被误用。

**验收**：状态栏所有文字对比度 ≥ 4.5:1。

## P2-5　分析面板按钮层级

**文件**：`src/components/AnalysisPanel.vue`

**现状**：4 个按钮尺寸完全相同（288×36），2 个实心蓝、2 个描边蓝。用户看不出哪个是主操作。

**改法**：按现有三段各留 **1 个**实心主按钮，其余降为描边或文字按钮：

| 段落 | 主按钮（实心） | 次要（描边/文字） |
| --- | --- | --- |
| 覆盖分析 | 在地图上显示覆盖范围 | 显示覆盖图层 → **改为文字切换**（`显示 / 隐藏覆盖图层`） |
| 可达性 | 计算区县可达性 | 两个导出 → 保留文字链接，不加边框 |
| 等时圈 | 计算等时圈 | 无 |

**验收**：面板内实心蓝按钮 ≤ 3 个且分属三个不同段落；同一段落内不存在两个同等权重的按钮。

**文件**：`src/components/SidePanel.vue`

**现状**：分组区底部（y≈650）到「收起」按钮（y≈848）约 200px 纯空白，无内容收口。
