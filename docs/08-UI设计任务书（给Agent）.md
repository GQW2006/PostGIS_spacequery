# UI 设计任务书（可直接交给 AI Agent 实现）

| 项 | 内容 |
| --- | --- |
| 文档版本 | v1.0 |
| 使用者 | AI 前端 Agent |
| 设计定位 | 专业 GIS 工作台：**地图优先、数据说话、克制不花哨** |
| 技术约束 | Vue 3 `<script setup>` + Mapbox GL JS；不引入重型 UI 库，组件自写 |

> **给 Agent 的指令**：本文档中所有尺寸（px）、颜色（hex）、间距均为**强制值**，
> 不要自行"优化"。§6 的六个状态必须全部实现，不能只做正常态。

---

# 1. 设计原则（实现时对照）

1. **地图是主角**。面板总宽 ≤ 屏幕 30%，且可收起。
2. **一眼看懂，再看细节**。先给颜色和数量，点击后才给属性。
3. **所有视觉编码可解释**。每个颜色/符号必须能在图例里找到对应。
4. **不做花哨动效**。只在"地图飞行定位"和"抽屉展开"两处用过渡，其余即时响应。

**实现要求**

├────────────────────────────────┤

**行为**

- 点击地图要素 → 抽屉从右滑入，`transform: translateX(100%) → 0`，`200ms ease-out`
- 点击 `╳` 或按 `Esc` → 滑出
- 点击另一个要素 → 内容替换，不重新滑入

# 5. 地图与交互

## 5.1 缩放级别策略

| 缩放 | 显示 |
| --- | --- |
| Z < 9 | 区县面 + 聚合气泡 |
| 9–12 | 聚合气泡 + 区县名标注 |
| ≥ 12 | 原始点位 + 设施名标注 |
| ≥ 15 | 增加道路名 |

## 5.2 四个核心交互流程

### ① 查"附近有什么"

```
点击地图任意位置
  → 打临时标记（主色圆环，脉冲一次）
  → 抽屉展开，显示：所属行政区
  → 下方列出：500m 内 2 所小学 / 1 所中学 / 3 个菜市场
  → 点击任一条 → flyTo 至该点 Z15 + 高亮
```

**要求**：一次点击同时给「归属 + 周边」，不要让用户点两次。

### ② 看某区县水平

```
点击区县面
  → 该区县高亮（外发光 #FAAD14 2px）
  → 抽屉显示：设施数 / 每万人设施数 / 平均最近距离
  → 底部「只看这个区」按钮
  → 点击后其他区县变灰（opacity .25），设施只留本区
```

### ③ 服务区覆盖分析

```
切到「分析」Tab
  → 选设施类型（默认小学）
  → 拖半径滑块（默认 1000m）
  → 松手后 500ms 计算，地图渲染缓冲区
  → 面板显示覆盖人口 / 覆盖率
  → 点「导出」→ 下载 GeoJSON
```

### ④ 搜索定位

```
顶栏输入关键词
  → 下拉显示前 10 条（名称 + 区县）
  → 回车或点击 → flyTo Z15
  → 抽屉打开显示详情
```

## 5.3 视口联动（防抖）

```js
map.on('moveend', debounce(() => {
  const bbox = map.getBounds();
  fetchFacilities(bbox);
}, 300));
```

**必须**：`moveend` + `300ms` 防抖。不要用 `move`（每帧触发）。

# 6. 六个状态（必须全部实现）

| 状态 | 表现 |
| --- | --- |
| **加载中** | 面板内骨架屏（3 行灰条动画），地图区不遮挡 |
| **空数据** | 插图 + `当前视口内没有设施` + 建议 `试试缩小地图范围` |
| **错误** | `统计服务响应超时` + `[重试]` 按钮，保留旧数据 |
| **空闲（首次）** | 左侧默认展开「图层」，地图定位成都全域，抽屉关闭 |
| **无网络** | 顶部细横幅 `网络已断开，数据可能不是最新` |
| **权限不足** | 按钮禁用 + `title="登录后可用"` |

> Agent 常见错误：只做正常态。**六个状态是验收项，缺一个算未完成。**

| 断点 | 调整 |

# 8. 可访问性

- 颜色信息必须有形状/文字作为第二编码
- 文字与背景对比度 ≥ 4.5:1
- 所有图标按钮有 `title` 或 `aria-label`
- 键盘可完成：搜索、切图层、`Esc` 关抽屉
- 抽屉本身就是地图的"文字版"，保证读屏可用

# 11. 禁止事项

1. 不要引入 Element Plus / Ant Design 等组件库，组件自写。
2. 不要用超过 4 种主色，配色严格按 §3。
3. 不要做页面级 loading 遮罩（会挡住地图）。
4. 不要用 `move` 事件做视口联动。
5. 不要在滑块 `input` 事件里发请求。
6. 不要用 emoji 当图标，用 SVG。
7. 不要写死 mock 数据——所有数字来自接口。
8. 不要忽略空态与错误态。
