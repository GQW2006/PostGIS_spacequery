## 各文档要点速览

### 00 开发计划

- 先认清现实（需求模糊、一个人干、两周要演示）
- **第一周的核心不是写代码，是把"可达性"定义清楚**
- 垂直切片推进，每个切片都能演示
- 附周计划、任务卡、口径确认模板

### 01 需求规格说明书

- 五大模块：地图 / 图层 / POI / 用户 / 分析
- 每个需求有编号、优先级、验收标准
- 权限矩阵、数据规范、非功能指标
- 里程碑 M1–M5

### 02 技术选型文档

- 前后端分离 + 双地理服务（Flask 业务查询 / GeoServer 大图层渲染）
- 前端：Vue3 + Vite + Mapbox GL + Pinia
- 后端：Flask + flask-smorest + SQLAlchemy + PostGIS
- 关键决策都写了"为什么"

### 03 UI 设计规范

- 专业 GIS 工作台定位，地图优先
- 三栏布局：顶栏 56 / 左面板 320 / 右抽屉 360 / 状态栏 32
- 完整色板、字号、地图符号规范
- 四条关键交互流程 + 空/错/加载三态

### 04 指标口径说明

- 项目性质是**求职作品集**，选型原则是"用可控工作量换最大能力信号"
- 主指标 **2SFCA**（同时考虑供给、需求、竞争），缓冲区与最近距离作对照
- 服务半径：小学 1000m / 中学 1500m / 菜市场 500m，前端可调
- 输出：100m 栅格 + 区县汇总 + 分位数分级面
- **含面试讲解提纲**（三个可展开的钩子和必须主动承认的局限）
